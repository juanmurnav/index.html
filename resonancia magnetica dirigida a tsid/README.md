# Resonancia magnética dirigida a TSID

Tests de autoevaluación basados en el libro **«Resonancia magnética para técnicos»** (Eloy Calvo Pérez, 2013), orientados a la OPE de Técnico Superior en Imagen para el Diagnóstico (SNS-Osasunbidea).

- 28 archivos, uno por capítulo del libro (`RM_CapNN_*.html`).
- Cada archivo contiene **8 tests de 25 preguntas** (200 preguntas por capítulo; 5.600 en total), con selector «Elige capítulo, bloque y test».
- Explicación tras cada respuesta, letras de respuesta correcta equilibradas y longitud de opciones compensada.
- Sin imágenes ni referencias a figuras.
- Donde el libro (2013) está desactualizado, las preguntas y explicaciones recogen la información vigente (p. ej., restricciones EMA 2017 a los quelatos lineales de gadolinio, lactancia tras gadolinio, equipos clínicos de 7 T, dispositivos condicionales para RM, límites IEC de SAR).

Uso personal de estudio.
