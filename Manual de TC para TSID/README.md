# Manual de TC para TSID

Carpeta creada para "Manual de TC para TSID".

Tests del libro de Costa y Soria, *Tomografía computarizada dirigida a técnicos superiores en imagen para el diagnóstico* (Elsevier, 2015): un HTML por capítulo (14), con 8 tests de 25 preguntas cada uno (200 por capítulo, 2.800 en total) y explicación tras cada respuesta. Modo estudio y modo examen. `index.html` enlaza todos los capítulos.

- Estilo y dificultad de los exámenes TER de Osasunbidea.
- Límites de dosis según la normativa española vigente: RD 1029/2022 (trabajadores y público) y RD 601/2019 (pacientes). El RD 783/2001 solo aparece como norma derogada.
- Sin imágenes ni referencias a figuras.
